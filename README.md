# Verb Study Practice Website

A lightweight, interactive web application built with HTML, Tailwind CSS, and vanilla JavaScript to help students practice and memorize English verb forms. 

## Features
* **Verb List:** A comprehensive master table of 66 common English verbs displaying base form, past tense, past participle, and present participle.
* **Flashcards:** An interactive UI to study verb variations by clicking to reveal answers.
* **Practice Quiz:** A typing-based quick quiz that randomly tests the user on different verb conjugations.

## Tech Stack
* HTML5
* Tailwind CSS (via CDN)
* Vanilla JavaScript
* Lucide Icons

## How to Run
Simply clone this repository and open `index.html` in your web browser. No local server or build tools are required!
